更新设置

Windows / macOS 客户端在应用内下载并安装更新,安装包按签名清单校验大小和 sha256; Linux / Android 客户端提示有新版本,点「下载」用浏览器打开下载直链。

生成客户端时填到 rdgen 的 Update Public Key。私钥在数据目录的 update_ed25519.key,丢失后已发出的客户端无法再更新,请备份。
rdgen 的 Config Server URL 须为 https://域名(443 端口、根路径),反向代理须透传 Host。
直链打开「123 鉴权」后,同步和下载跳转时用它生成 15 分钟内有效的鉴权直链;直链填 123 云盘复制的原始地址。
